# Fire TV demo

I recorded the original bridge running on Fire TV. The video shows camera selection and live playback, not the RC1 deployment.

- [Full 1080p demo](https://github.com/RenanEspinar/Alexa-RTSP-Bridge/blob/main/Alexa_RTSP_Bridge_FireTV_README_1080p.mp4)
- [Short animated preview](../images/firetv_preview.gif)
- [On-demand flow](../images/on_demand_flow.gif)

The GIF is sped up for the README; use the complete recording when discussing startup time. It is not a benchmark.

For new testing, record the camera model and codec, host hardware, first-frame delay, and actual FFmpeg stop/start events. Don't show camera passwords, OAuth tokens, signed HLS URLs, or names that reveal private locations.
